### 3. 核心竞争壁垒：MDI 全球格局

MDI（二苯基甲烷二异氰酸酯）是聚氨酯的核心原料，具有极高技术壁垒——**全球仅 7 家企业**拥有自主知识产权。

**全球 MDI 产能格局（2025）：**

| 排名 | 企业 | 全球份额 | 产能 |
|------|------|---------|------|
| 🥇 | **万华化学** | **~34%** | **380 万吨/年** |
| 🥈 | 巴斯夫 (BASF) | ~18% | — |
| 🥉 | 科思创 (Covestro) | ~16% | — |
| 4 | 亨斯迈 (Huntsman) | — | — |
| 5 | 陶氏 (Dow) | — | — |
| | **CR5 合计** | **~91%** | |

**中国 MDI 市场格局：** 万华化学占 **65%**，巴斯夫 ~14%，科思创 ~12%，**CR2 = 79%**，CR4 > 95%。

**核心竞争要素：**
- 光气资源稀缺 + 技术复杂度 → 天然寡头垄断
- MDI 被认定为"化工行业综合壁垒最高的大宗产品之一"
- 万华是国内**唯一**掌握 MDI 核心生产技术的企业
- 万华凭借成本优势享有定价权，MDI 是其盈利基本盘

### 5. 竞争优势总结

```

```

## 三、生益科技 (600183.SH)

### 1. 公司概况

| 项目 | 内容 |
|------|------|
| 全称 | 广东生益科技股份有限公司 |
| 英文名 | Shengyi Technology Co., Ltd. |
| 上市日期 | 1998-10-28 |
| 总部 | 广东省东莞市松山湖 |
| 所属行业 | 电子 — 元件 |
| 成立时间 | 1985 年 |
| 全球地位 | **刚性覆铜板全球第二（2013~至今）** |

### 2. 主营架构

| 产品 | 说明 |
|------|------|
| **覆铜板（CCL）** | 核心产品，PCB 的第一大原材料成本（~30%） |
| 粘结片（半固化片） | 多层板关键材料 |
| 印制线路板（PCB） | 通过子公司生益电子（688183）生产 |

2025 年 CCL 销量：**14,371.48 万平米**（+17.03%）

### 3. 全球覆铜板（CCL）竞争格局

据 Prismark，全球刚性覆铜板行业 **CR5 = 55%**（2008 年 ~52.6%），集中度高且持续提升。

| 排名 | 企业 | 全球份额 | 地区 |
|------|------|---------|------|
| 🥇 | 建滔积层板 | 10-15% | 中国香港 |
| 🥇 | **生益科技** | **10-15%** | **中国大陆** |
| 🥇 | 台光电子 | 10-15% | 中国台湾 |
| 4 | 南亚塑胶 | 5-10% | 中国台湾 |
| 5 | 松下 (Panasonic) | 5-10% | 日本 |
| | **CR5 合计** | **>55%** | |

**关键对比：** 下游 PCB 行业 CR5 不足 30%，CCL 行业格局明显优于 PCB，拥有更强定价权。

### 4. AI 驱动的升级逻辑

| 阶段 | 内容 |
|------|------|
| **传统 CCL** | 普通 FR-4，单价低，竞争激烈 |
| **AI 需求** | AI 服务器/交换机需要 M8、M9 高端 CCL |
| **技术升级** | 低损耗、高散热、高信号完整性 |
| **价值提升** | M9 CCL 单张价值量数倍于普通 CCL |
| **产能扩张** | 江西厂 +120 万张/月、泰国厂 +70 万张/月 |

**客户拓展：** 从 GPU AI 服务器（NVIDIA 链）扩展到 **ASIC AI 服务器**（AWS、Meta、Google）

### 5. 关键财务（2025 年报）

| 指标 | 数值 | 同比 |
|------|------|------|
| 营业收入 | **284.31 亿** | **+39.45%** |
| 归母净利润 | **33.34 亿** | **+91.75%** |
| 利润总额 | 44.16 亿 | +113.57% |
| 经营性现金流 | 52.74 亿 | **+262.17%** |
| 毛利率（1Q26） | 28.1% | 环比提升（4Q25 为 25.8%） |
| 股利支付率 | 87% | — |

### 6. 竞争优势总结

```
🏆 全球刚性覆铜板第二（连续 12 年）
🏆 国内覆铜板绝对龙头
🏆 CCL 行业格局优于 PCB（CR5=55% → 定价权更强）
🏆 AI 高端 CCL (M8/M9) 技术突围，内资替代
🏆 产能紧俏：订单超月 1000 万张 > 产能 ~850 万张
🏆 江西+泰国双基地扩产中
🏆 2025 年利润翻倍（+92%），AI 驱动的业绩爆发期
```
